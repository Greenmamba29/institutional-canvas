Anti-Sniping Protection

When a bid is placed within the final minutes of an auction, the end time automatically extends by a configurable period (default: 2 minutes). This prevents last-second bid manipulation and ensures fair price discovery for all participants.

Realtime Architecture

Auction state is broadcast via Supabase Realtime WebSocket channels. Every bid triggers instant UI updates across all connected participants. The auction_bids table uses RLS to protect bid amounts until auction completion.

Deal Auto-Creation

Upon auction settlement, a deal record is automatically generated linking the winning bidder to the seller. This feeds into the chain-of-custody tracking system for complete transaction lifecycle visibility.

7. Security Architecture
Row Level Security (RLS)

Every table has RLS policies. Users can only access data belonging to their organization. All SELECT queries are filtered at the database level.

SECURITY DEFINER RPCs

All write operations go through stored procedures with SECURITY DEFINER. Prevents direct INSERT/UPDATE/DELETE from the client.

Edge Function Auth

Every edge function validates the JWT token from the Authorization header. Subscription tier is checked before gated operations execute.

Webhook Signature Verification

Stripe webhooks verify the signature header against the endpoint secret. Prevents spoofed payment events and subscription manipulation.
